# paid release plan

this app stays free for the current version.

when a later version is paid:

- sell a one time license for that version
- ship a signed and notarized dmg or zip
- require a license key or login in the app
- check the license online the first time
- cache the result so the app still works offline after activation

what this does:

- stops casual sharing of the paid build
- keeps the download separate from the license
- lets people keep using any version they already got for free

what it does not do:

- it does not stop someone from copying the dmg
- it does not fully stop license sharing
- it does not make the app impossible to crack

standard model:

- free community version now
- paid pro version later
- limited activations per purchase
- free minor updates, paid major upgrades if needed
